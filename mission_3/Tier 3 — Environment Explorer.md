# Tier 3 — Environment Explorer: A Beginner's Guide to Python Environments

## 1. IDLE (The Built-in Default)
When you install Python, it comes with a program called **IDLE** (Integrated Development and Learning Environment). 
*   **What it is used for:** IDLE is perfect for absolute beginners. It has a simple interface, syntax highlighting (it colors your code to make it easier to read), and an interactive shell (a place where you can type one line of code and instantly see the result).
*   **How to use it:** You can open IDLE, go to `File > New File`, type your code, save it, and press `F5` to run it.

## 2. Visual Studio Code (VS Code)
**What it is used for:** VS Code is a free, powerful, and highly popular code editor developed by Microsoft. While it is not a dedicated "Python IDE" out of the box, installing the official Python extension turns it into a world-class Python environment.
*   **Why use it:** It supports massive projects, has excellent debugging tools, integrates with Git, and has a built-in terminal so you can run your code without leaving the window.

## 3. PyCharm (Community Edition)
**What it is used for:** PyCharm is an IDE built specifically for Python by JetBrains. The free "Community Edition" is excellent for beginners. 
*   **Why use it:** It is like a powerful cockpit. It auto-completes your code, catches errors before you even run the program, and manages complex project folders. It is heavier than VS Code but tailored strictly for Python.

## 4. Creating and Running a Simple Python Script
No matter which environment you use, the steps to create and run a script are generally the same:
1.  Open your chosen editor (e.g., VS Code or IDLE).
2.  Create a new file and save it as `hello.py`. (The `.py` extension tells the computer it is a Python file).
3.  Type the following code into the file:
    ```python
    print("Hello, Python!")

4. Run the file. In IDLE, press F5. In VS Code, click the "Play" button in the top right corner (or right-click and select "Run Python File in Terminal").

5. Look at the output window. You will see: Hello, Python!
