## 🏗️ Technical Architecture & Features

* **True Trapezoid Geometry:** Built using modern CSS `clip-path` polygons to represent widening foundational layers and narrowing specialization toward the apex.
* **Responsive Interactive UI:** Features a left-aligned tier structure, interactive timeline dots, keyboard navigation (`←` / `→` arrow keys), and a dynamic right-hand detail drawer.
* **Subfield Color-Coding:** Color-keyed legend distinguishing Foundations, Symbolic AI, Machine Learning, Deep Learning, Generative AI & LLMs, and Future/AGI milestones.

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Click any milestone node or use your left/right arrow keys to explore the historical notes.
